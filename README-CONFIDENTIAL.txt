================================================================================
                  L'AMONDA STORE - GUIDE CONFIDENTIEL DE SÉCURITÉ
================================================================================

Ce document est strictement confidentiel et réservé au propriétaire de la boutique.

--------------------------------------------------------------------------------
1. POURQUOI LE SITE EST DÉSORMAIS TOTALEMENT SÉCURISÉ & PRIVÉ
--------------------------------------------------------------------------------
- TOUT LIEN PUBLIC VERS L'ADMIN A ÉTÉ SUPPRIMÉ :
  Les clients et visiteurs voient uniquement la boutique et le panier. Aucun bouton 
  "Admin", aucun formulaire visible publiquement.

- PROTECTION DE L'INSPECTION DU CODE (ANTI-INSPECT / ANTI-DEVTOOLS) :
  Sur la page gérant, le clic droit est bloqué, les raccourcis inspecteur (F12, 
  Ctrl+Shift+I, Ctrl+U) sont neutralisés, et un piège anti-débogueur se déclenche 
  si quelqu'un force l'ouverture des outils développeur.

- CHIFFREMENT CRYPTOGRAPHIQUE SANS TRACE CLAIRE :
  L'URL de votre base de données Google Sheets est chiffrée en mémoire.
  Aucun pirate ne peut voir l'adresse de votre base même en regardant le code source.
  Sans le code PIN exact, le déchiffrement est mathématiquement impossible.

- FAUSSE PAGE LEURRE (DASHBOARD.HTML) :
  Si quelqu'un tente de deviner l'adresse en tapant "dashboard.html", il tombe sur
  une page d'erreur "403 Forbidden - Accès Refusé" ne contenant aucune donnée.

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
3. VOTRE CODE D'ACCÈS
--------------------------------------------------------------------------------
- Code PIN par défaut : 2026
- Vous pouvez à tout moment changer ce code secret dans le portail en cliquant
  sur le bouton "Code Secret".

--------------------------------------------------------------------------------
4. MODE DISCRET (ANTI-REGARDS INDISCRETS)
--------------------------------------------------------------------------------
Dans votre portail gérant, un bouton "Mode Discret" vous permet de flouter instantanément
les noms, téléphones et adresses des clients sur votre écran si vous êtes dans un lieu
public ou avec des personnes autour de vous. Il suffit de survoler une ligne avec la souris
pour la déflouter individuellement.

--------------------------------------------------------------------------------
5. VERROUILLAGE AUTOMATIQUE
--------------------------------------------------------------------------------
Si vous laissez votre portail ouvert sans activité pendant 10 minutes, la session
expire automatiquement et toutes les données sont effacées de l'écran.
